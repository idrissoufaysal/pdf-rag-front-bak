Une question avancée à poser à ton étudiant

Demande-lui :

"Si React réexécute les composants tout le temps, pourquoi mon application n'est-elle pas lente ?"

La réponse :

Parce que React :

utilise une représentation virtuelle de l'interface,
compare les changements,
applique seulement les différences nécessaires au DOM réel.

La prochaine notion importante après ça sera :

"Le cycle de vie moderne d'un composant React : Render phase, Commit phase, pourquoi useEffect arrive après le rendu, et pourquoi les boucles infinies arrivent."

C'est une notion que beaucoup de développeurs React utilisent sans vraiment la comprendre.
